# Security Policy

## Supported Versions

| Version    | Supported          |
|------------|--------------------|
| <= 1.5.6   | :x:                |
| >= 2.4.1.4 | :x: |
| >= 3.0.0   | :white_check_mark: |

## Reporting a Vulnerability

Open an Issue on this github and it will be triaged and solved.
